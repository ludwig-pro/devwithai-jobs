# Dev With AI · Jobs Board

Tableau filtrable des offres partagées sur le Slack Dev With AI (`#jobs`).

## Stack

- Next.js (App Router) + TypeScript
- CSS custom (tokens Dev With AI)
- Data: `data/board.jsonl`

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## V1 scope

- Search + chips Remote / CDI / Freelance / IA
- Listing dense, click → URL externe ou permalink Slack
- Pas d’auth, pas de page détail, pas de formulaire de post
